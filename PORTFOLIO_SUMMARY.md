# InternConnect — Portfolio Summary

## Project
**InternConnect — Web-Based Internship Management Platform**

## Purpose
A centralized internship platform for students, companies, and administrators.

## My Development Work
- Designed the system requirements and user workflows
- Designed the relational database structure
- Developed PHP backend functionality
- Built Student, Company, and Admin workflows
- Implemented authentication and role-based access
- Implemented internship posting and approval
- Implemented internship application and status management
- Implemented resume upload and cover-letter submission
- Built the web interface using HTML, CSS, and JavaScript
- Tested and corrected system errors during development

## Main Workflow

Student:
Register → Complete Profile → Browse Internship → View Details → Apply → Track Status

Company:
Register → Company Profile → Create Internship → Admin Review → Manage Applicants → Accept/Reject

Admin:
Login → Monitor System → Review Internship → Approve/Change Status → Monitor Users and Activity

## Technologies
PHP, MySQL, HTML, CSS, JavaScript, XAMPP, MySQL Workbench, Visual Studio Code
